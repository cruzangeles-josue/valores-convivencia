# Valores y Convivencia

## Descripción

Este proyecto es un sitio web educativo sobre los valores y la convivencia.

El objetivo es promover valores como el respeto, la honestidad, la solidaridad y la responsabilidad mediante información, un cuestionario interactivo y un formulario de contacto.

- CSS3
- JavaScript
- Git
- GitHub
